Hunyuan3D-2.1 Stage 1 · Forward Process

Step-by-step walkthrough from a single RGBA image to an untextured mesh, with tensor shapes at every stage

1
Input Image Preparation
pipelines.py → prepare_image() → image_processor()

The user provides a single image (RGBA preferred). The background remover converts RGB→RGBA by segmenting the object. The image processor normalises pixel values to [−1, 1] and returns them as a tensor.

PIL Image H×W (arbitrary) → BackgroundRemover → resize, center-crop, normalize → [B, 4, 224, 224] float32, ∈[−1,1]
The alpha channel carries the background mask. Images already RGBA skip background removal.
2
Image Encoding (Conditioner)
conditioner.py → DualImageEncoder → CLIP + DINOv2

The frozen dual encoder produces two sets of patch tokens that will condition the DiT. Both encoders use ViT-style patch-based processing: divide 224×224 into 14×14-pixel patches → 16×16 = 256 patches, plus 1 [CLS] token.

EncoderInputOutputRole in DiT
CLIP ViT-L/14 [B, 3, 224, 224] [B, 257, 1024] cond['main'] — cross-attn keys/values; pooled to build c
DINOv2-Giant [B, 3, 224, 224] [B, 257, 1536] cond['additional'] — projected & appended during dual-CFG

For classifier-free guidance the encoder is also called with a zero (unconditional) embedding. The two outputs are concatenated → the DiT processes a batch of 2× (or 3× for dual guidance) the user batch size internally.

cond['main'] [2B, 257, 1024] cond['additional'] [2B, 257, 1536]
3
Latent Initialization
pipelines.py → prepare_latents()

The 3D shape latent space is a set of 4096 tokens, each with 4 channels — the "VecSet" representation. Sampling starts from pure Gaussian noise at t = T = 1.

shape = (batch_size, *vae.latent_shape)  # vae.latent_shape = (4096, 4)
latents = randn_tensor(shape)              # [B, 4096, 4]  standard Gaussian
latents *= scheduler.init_noise_sigma      # scale by scheduler (usually 1.0)
z_T [B, 4096, 4] ~ N(0,1)
The 4096 tokens do not correspond to a regular grid. They are unordered latent points in 3D-shape space — more tokens are implicitly assigned to edges/corners by the VAE's importance sampling during training.
4
Flow-Matching ODE Loop (50 steps)
pipelines.py → __call__() → for t in timesteps

Hunyuan3D uses rectified flow matching. The ODE integrates a learned velocity field v_θ from z_T back to z_0. At each step:

for i, t in enumerate(timesteps):            # t counts down 1000 → 0
    latent_input = cat([latents] * 2)        # CFG: [2B, 4096, 4]
    noise_pred = model(latent_input, t, cond)   # DiT forward pass (below)

    # CFG combination
    v_cond, v_uncond = noise_pred.chunk(2)
    v = v_uncond + guidance_scale * (v_cond - v_uncond)   # [B, 4096, 4]

    latents = scheduler.step(v, t, latents).prev_sample    # [B, 4096, 4]
The scheduler performs: z_{t-1} = z_t − v · Δt (Euler step) or a higher-order method. guidance_scale defaults to 7.5.
5
DiT Forward Pass (inside each ODE step)
hunyuandit.py → HunYuanDiTPlain.forward()

5a. Embed input latent and timestep

x = self.x_embedder(x)          # Linear(4 → 1024):   [2B, 4096, 4] → [2B, 4096, 1024]

t_emb = self.t_embedder(t)        # sinusoidal + MLP:   [2B] → [2B, 1, 1024]

extra = self.pooler(cond)          # AttentionPool over 257 CLIP tokens: [2B, 257,1024]→[2B,1024]
c = t_emb + self.extra_embedder(extra)  # MLP(1024→4096→1024):  [2B, 1, 1024]
x [2B, 4096, 1024] c [2B, 1, 1024]

5b. Prepend conditioning token

x = torch.cat([c, x], dim=1)     # [2B, 4097, 1024]  token 0 = 'class' token
x [2B, 4097, 1024]
Token 0 carries timestep and image-pooling conditioning. Tokens 1–4096 are the 3D latent tokens.

5c. U-Net transformer blocks

skip_value_list = []
for layer, block in enumerate(self.blocks):    # 21 blocks total
    skip_value = None if layer <= 10 else skip_value_list.pop()
    x = block(x, c, cond, skip_value=skip_value)  # [2B, 4097, 1024] → [2B, 4097, 1024]
    if layer < 10:
        skip_value_list.append(x)              # encoder saves output for symmetric decoder block
Block rangeRoleskip_linearFFN typeI/O shape
0 – 10EncoderNoneMLP (1024→4096→1024)[2B, 4097, 1024]
11 – 14DecoderLinear(2048→1024)MLP (1024→4096→1024)[2B, 4097, 1024]
15 – 20DecoderLinear(2048→1024)MoE (8 experts, top-2)[2B, 4097, 1024]

5d. Inside each HunYuanDiTBlock

# --- Decoder blocks only (layers 11-20) ---
if self.skip_linear is not None:
    cat = torch.cat([skip_value, x], dim=-1)  # [2B, 4097, 2048]  (concat over channel)
    x = self.skip_linear(cat)                  # Linear(2048→1024): [2B, 4097, 1024]
    x = self.skip_norm(x)

# --- All blocks ---
x = x + self.attn1(self.norm1(x))             # Self-Attn: Q=K=V from x  [2B, 4097, 1024]
                                               #   heads=16, head_dim=64, scaled dot-product attn
x = x + self.attn2(self.norm2(x), text_states) # Cross-Attn: Q from x, K/V from CLIP
                                               #   Q [2B, 4097, 1024] × KV [2B, 257, 1024]
mlp_in = self.norm3(x)
x = x + self.moe(mlp_in)   # MoE: 8 experts (each: 1024→4096→1024), top-2 gating
# OR:
x = x + self.mlp(mlp_in)   # MLP: 1024→4096→1024  (GELU)
Self-Attention note: all 4097 tokens attend to all other 4097 tokens. The class token (pos 0) mixes timestep/image conditioning into the latent stream at every block.
Cross-Attention note: 4097 latent tokens form Q, while the 257 CLIP patch tokens form K and V. This is how the image is "read" by the DiT — not as additional latent tokens, but as external memory.

5e. FinalLayer

x = self.final_layer.norm_final(x)   # [2B, 4097, 1024]
x = x[:, 1:]                         # drop class token  →  [2B, 4096, 1024]
x = self.final_layer.linear(x)       # Linear(1024→4):   [2B, 4096, 4]
return x                              # velocity prediction  v_θ(z_t, t, cond)
v_θ [2B, 4096, 4] (noise/velocity prediction)
6
Classifier-Free Guidance + ODE Update
pipelines.py → __call__() (inside the 50-step loop)
v_cond, v_uncond = noise_pred.chunk(2)          # each [B, 4096, 4]
v = v_uncond + guidance_scale * (v_cond - v_uncond)  # [B, 4096, 4],  scale=7.5

latents = scheduler.step(v, t, latents).prev_sample  # z_{t-1} = z_t - v·Δt
z_t [B, 4096, 4] v [B, 4096, 4] → ODE step → z_{t-1} [B, 4096, 4]

This loop runs 50 times. After the loop, z₀ is the clean 3D latent.

For dual guidance (dual_guidance=True), the DiT runs on 3× batch (cond, partial-uncond, full-uncond) and a more complex combination formula is used.
7
ShapeVAE Decode — Latents to Feature Field
model.py → ShapeVAE.forward() → post_kl + Transformer

The clean latent z₀ is first de-scaled (divided by the VAE's learned scale factor), then decoded by two sub-networks:

latents = 1.0 / vae.scale_factor * latents    # [B, 4096, 4]  (scale_factor learned during VAE training)

# 1. Project latent channels to model width
latents = vae.post_kl(latents)                  # Linear(4 → 1024): [B, 4096, 1024]

# 2. Refine with a self-attention Transformer
latents = vae.transformer(latents)              # 8 ResidualAttentionBlocks, width=1024, heads=16
                                               # output: [B, 4096, 1024]  — richer per-token geometry context
z₀ [B, 4096, 4] → latents [B, 4096, 1024] (feature vectors, one per vecset token)
These 4096 feature vectors are the "memory" that the geo_decoder will query to reconstruct the SDF at any 3D point. Each vector implicitly encodes the local geometry around some region of the 3D shape.
8
Volume Decoding — SDF at Every Grid Point
volume_decoders.py → VanillaVolumeDecoder + CrossAttentionDecoder

The volume decoder builds a dense 3D query grid and asks the geo_decoder: "what is the SDF value at each grid point?"

8a. Generate query grid

bbox = [-1.01, -1.01, -1.01, 1.01, 1.01, 1.01]
octree_resolution = 384
# np.linspace(-1.01, 1.01, 385) per axis
xyz_samples: shape = [385³,  3]  =  [57_289_025, 3]   # 57.3M query points

8b. Chunked geo_decoder inference (chunk=8000)

for start in range(0, 57_289_025, 8000):   # ~7162 iterations
    chunk = xyz_samples[start : start+8000]   # [8000, 3]
    chunk = repeat(chunk, "p c -> b p c", b=B)  # [B, 8000, 3]

    # Fourier positional embedding of 3D coordinates
    pe = fourier_embedder(chunk)                # 8 freqs, sin+cos+input  →  [B, 8000, 51]
                                               # 3 × (8×2 + 1) = 51 dims

    # Project to model width and cross-attend to latents
    q = query_proj(pe)                          # Linear(51→1024):  [B, 8000, 1024]
    feat = cross_attn_decoder(q, latents)       # Q=[B,8000,1024]  KV=[B,4096,1024]  →  [B, 8000, 1024]
    logits = output_proj(feat)                  # Linear(1024→1):   [B, 8000, 1]
    batch_logits.append(logits)

grid_logits = cat(batch_logits, dim=1)        # [B, 57_289_025, 1]
grid_logits = grid_logits.view(B, 385, 385, 385)  # [B, 385, 385, 385]  float32
TensorShapeDescription
chunk (xyz)[B, 8000, 3]3D coordinates of query points
Fourier PE[B, 8000, 51]sin/cos positional encoding of xyz
Query embed[B, 8000, 1024]projected query
Cross-attn output[B, 8000, 1024]each query enriched by latents
SDF logit[B, 8000, 1]signed distance value per point
Full SDF grid[B, 385, 385, 385]the complete 3D occupancy field
Volume decoding is the slowest step: ~7162 cross-attention calls × [B, 8000, 1024] queries × [B, 4096, 1024] keys. This is why the profiler shows ~28–31 s here.
9
Surface Extraction — Marching Cubes
surface_extractors.py → MCSurfaceExtractor → skimage.measure.marching_cubes

The SDF grid's zero-level-set (where values cross from negative to positive) defines the object surface. Marching cubes extracts this as a triangle mesh.

vertices, faces = marching_cubes(
    grid_logit,            # [385, 385, 385]  float32 SDF
    level=-1/512,           # iso-value (slightly negative to get solid exterior)
    spacing=(2.02/384,) * 3  # physical spacing of grid voxels
)                          # vertices [V, 3],  faces [F, 3]
[385, 385, 385] SDF → vertices [V, 3] (float32, world coords) faces [F, 3] (int, triangle indices)
V and F depend on shape complexity — typically 30k–150k vertices, 60k–300k faces for the default 384³ resolution.
10
Output — trimesh.Trimesh (untextured GLB)
pipelines.py → export_to_trimesh() → mesh.export()
mesh = trimesh.Trimesh(mesh_v, mesh_f)   # wrap raw arrays
mesh.export("output.glb")               # save as binary glTF

The result is an untextured 3D mesh in world space, normalized to fit inside [−1,1]³. Stage 2 (PBR texture generation) reads this GLB and adds albedo/metallic-roughness/normal maps.
